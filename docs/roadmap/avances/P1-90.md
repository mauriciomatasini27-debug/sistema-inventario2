P1-90: test de regresión para la carga de cuentas en /panel/consumos.

## Decisión
El fix P1-48 vive en `crearCargadorCuentasConsumos` (`src/lib/panel-consumos-carga.ts`).
La página importa ese módulo en lugar de cachear la promesa inline.
El test importa el mismo módulo: dos `cargar()` seguidos deben llamar a `pedir()` dos veces.
Si alguien reintroduce `if (cuentasPromesa) return cuentasPromesa` en `cargar()`, el test falla.
Se eliminó `tests/feedback-loop-bug.test.ts` porque duplicaba el patrón en el spec.
