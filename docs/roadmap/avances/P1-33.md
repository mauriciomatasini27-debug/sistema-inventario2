P1-33: el botón piloto no queda disabled si `/api/admin/salud` cuelga tras el alta.

## Decisión
Tras P1-32 el éxito hacía `await cargarSalud()`; si salud no responde el `finally`
nunca corre y el botón queda disabled (parece que "no funciona").
El resultado del piloto vive en `#piloto-resultado` y salud no lo pisa.
`cargarSalud` se dispara sin await. Cada POST tiene AbortController a 50s.
El UI muestra paso 1/2 y 2/2 para ver en qué POST se traba.
No cambia el contrato de las keys ni de decidirAlta.
