P10-31: `check-comment-ids` valida el id y la clase de cada `//`, no del bloque contiguo.

## Decisión
- La unidad de validación de comentarios de línea pasa de bloque contiguo a línea individual.
- `agruparBloquesLinea` sigue en la librería de escaneo, pero el check ya no lo usa para ids.
- Cada línea con id desconocido, sin id o sin clase reporta su propio número de línea.
- Se reutilizan `mensajeIdDesconocido`, `mensajeSinId` y `mensajeSinClase`, sin vocabulario nuevo.
- Bloques (`/* */`), JSDoc y HTML conservan su regla actual.
- No cambia la política de ids/clases ni el formato del reporte de `verify`.
- Regresión: `// #299:` seguido de `// TB-165 [tenant]: …` ahora falla y nombra la primera línea.
