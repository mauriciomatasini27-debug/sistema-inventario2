P10-18 pendiente: el descarte del catálogo sugerido es por tenant, no por dispositivo como pedía STOCK-S7.

## Decisión
`POST /api/stock/plantilla` con `nombres: []` registra una fila en `tenant_product_seeds` con `cantidad = 0` (`src/pages/api/stock/plantilla.ts:54-77`).
El aviso se oculta para todo el tenant, no solo para el navegador que lo descartó.
`PRD-STOCK-01` y `ADR-0107` ya se corrigieron para describir el comportamiento real y dejar la decisión abierta.
Si Mauri quiere descarte por dispositivo, la opción es una clave local por tenant, análoga a `offline:catalogo:<tenantId>`.
No requiere migración si se elige la clave local.
Es un cambio chico de UI más un test de dos dispositivos.
