P1-48: el dueño crea una cuenta de servicio desde /panel/consumos.

## Decisión
El alta ya vivía en POST /api/service-accounts. El panel solo listaba.
El formulario pide servicio, proveedor y titular, el mínimo del schema.
Un 201 anula cuentasPromesa y vuelve a cargar la lista y el selector de cuentas.
Un 409 muestra el texto de cuenta duplicada. Un 422 marca el campo.
No hay alta manual de factura. El origen del schema no tiene un valor de panel.
