P1-69: wrapper `db:migrate` por idx de journal que saltea tablas ausentes y no reescribe SQL applied.

## Decisión
`drizzle-kit migrate` se corta si un SQL applied cambió de hash o si el tag toca una tabla que esa base no tiene.
El wrapper cuenta filas en `__drizzle_migrations` y aplica solo la cola del journal (`slice(n)`).
Cada statement con tabla ausente se saltea y se loguea; el hash del archivo igual se registra.
No se editan `drizzle/*.sql` ya aplicados: el delta va en un tag nuevo.
`db:migrate:kit` queda como escape hatch del kit crudo.
`db:migrate:check` lista pendientes y sale 2 si hay cola.
