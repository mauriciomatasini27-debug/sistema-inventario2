TB-163 #163: el shell del tablero B aplica void y charcoal a todas las pantallas del panel; Stock suma acciones rápidas y resumen; Fiado muestra cartera con saldo vía APIs existentes; Vender y admin usan el mismo fondo oscuro.

## Decisión
La piel B no queda solo en Inicio: PanelShell reasigna los tokens `--tema-*` dentro de `.tablero` para que caja, reportes, alertas y el resto hereden cards e inputs oscuros sin reescribir cada formulario.
El documento y la barra inferior siguen en void y charcoal; las subpáginas ya no dependen del tema claro del dispositivo para verse operativas.
Stock suma acciones rápidas arriba y un resumen de catálogo; Fiado muestra cartera con saldo usando solo GET `/api/credit/customers` y `/api/credit/balance`.
Vender y admin alinean el fondo del documento con void para no contrastar con el chrome del tablero.
Los tests `tb-163-panel-tablero` cubren shell, safe-area, reduced-motion y ausencia de `/panel/clientes`.
Caja, compras, servicios, reportes y ajustes quedan cubiertos por el shell; listas tipo prototipo en proveedores o más detalle en caja van en un PR chico posterior.
