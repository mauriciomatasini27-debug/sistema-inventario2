P1-58: el escaneo EAN en /venta offline resuelve el SKU con el mapa local de códigos.

## Decisión
El snapshot local pasa a versión 2 y guarda `codigos` al lado de `productos`.
Cada clave es un código de barras en mayúsculas y el valor es el SKU.
El pull agrega `catalogo.codes` leído de `product_codes`.
Si ese campo no viene, el mapa queda vacío.
Un snapshot v1 no se convierte en v2.
La lectura lo trata como ausente y la próxima descarga con red lo reemplaza.
El alta provisorio no crea un código de barras y copia el mapa que el snapshot ya tenía.
Sin red, `resolverLectura` busca el EAN en ese mapa antes de llamar a `/api/products`.
