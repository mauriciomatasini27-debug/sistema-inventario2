P1-10: `npm run check:numeros` falla si una rama reusa números de migración drizzle, ADR o avance que main ya reservó.

## Decisión
La guarda compara el árbol de la rama contra `origin/main` (o `main` si no hay remoto) y nombra la renumeración concreta con el siguiente número libre de main.
Cubre el caso real de #207: migraciones 0029/0030 y ADR-0098/0099/0100 contra main con 0029 y ADR-0101.
Corre dentro de `npm run verify` como paso `numeros`, junto a la guarda de docs generados.
`npm run siguiente-numero` imprime el próximo número libre de migración, ADR y avance mirando main.
Sin migración ni cambio de base de datos.
