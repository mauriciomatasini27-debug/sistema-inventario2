P1-52: /panel/caja lista, carga y deshace comprobantes QR con /api/cash/qr.

## Decisión
El API ya listaba, ingería y deshacía. El dueño tenía que mandarlo con curl.
La tarjeta muestra la lista y pide el número y el monto. El POST manda origen manual fijo, porque el esquema también acepta bot y gmail y esta pantalla no los ofrece.
Cada alta manda una Idempotency-Key. Un 201 y un deshacer refrescan la lista. Un 409 de duplicado dice que ese número ya está cargado.
La lista pide GET sin filtro. El alta no manda fecha de operación. Esos dos quedan en el API para el bot y para Gmail.
Retiros, reversas, export, cierre, turnos y el alta de vencimientos no cambian.
