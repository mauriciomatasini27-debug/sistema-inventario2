P1-87: el panel admin lista tenants desde la base de control y suspende o reactiva con el id escrito.

## Decisión

El Map `control.tenants` sigue siendo el registro de runtime. `GET /api/admin/tenants` vuelca la tabla `tenants` ahí antes de listar, y no borra entradas que la base no devolvió.
Si el id ya está en memoria, la base pisa estado, plan, slug, nombre, trial, demo, rubro y dueño. Moneda y `requestKey` de memoria quedan.
Sin `CONTROL_DATABASE_URL` el listado sigue saliendo solo del Map.
`POST` suspender|reactivar muta el Map y escribe `tenants.estado`. Si el id no está en memoria, un vuelco previo alcanza para un proceso frío.
El panel pinta la tabla `#tenants-tabla` y pide motivo más el id completo. No muestra email ni edita nombre o plan.
Sin migración nueva. La columna `estado` ya existe.
