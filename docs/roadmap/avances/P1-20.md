P1-20: /api/health reporta presencia de env Google/DB/Jobs sin filtrar valores.

## Decisión

`GET /api/health` suma `tieneGoogle`, `tieneDb` y `tieneJobs` como booleans
vía `leerVarEntorno`, sin devolver secretos. Sirve para ver si el runtime de
Vercel inyecta las vars de Production cuando login sigue en 500 y caja en
memoria. Es diagnóstico temporal: se saca cuando Production las lea. El
cliente de sync sigue usando solo `ok` y `ahora`.
