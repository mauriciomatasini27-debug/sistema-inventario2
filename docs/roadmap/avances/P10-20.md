P10-20 parcial: se implementó el fail-closed del registro de ventas en modo multiempresa; queda pendiente ejecutar la verificación local.

## Decisión
En `src/modules/sales/registro_venta.ts`, las fallas de lectura de idempotencia, snapshot de costos, transacción y relectura ante conflicto propagan `BaseNoDisponible` en modo multi.
El fallback a memoria se conserva para modo single, donde sigue siendo parte del funcionamiento de Slice-0 y de los tests sin PostgreSQL.
La prueba `tests/pers2-venta-fail-closed.test.ts` comprueba que la falta de base del tenant rechaza la operación y no modifica el espejo en memoria.
No requiere migración SQL.
Verificación local pendiente: `npm run typecheck`, `npm run check:arch` y `npm run verify` con Node 22 y PostgreSQL A/B.
