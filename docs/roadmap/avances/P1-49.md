P1-49: /panel/caja registra un retiro a caja fuerte con POST /api/cash/drops.

## Decisión
El API de retiros ya existía. El dueño tenía que mandarlo con curl.
La tarjeta manda la fecha de la jornada, el monto, el motivo si hay, quién lo carga y si el conteo es sorpresa.
La fecha arranca en el día civil de Buenos Aires, el mismo corte que el cierre.
El POST manda JSON y una Idempotency-Key nueva, después de confirmar.
Un 201 refresca el saldo y el historial, y muestra el drop_id.
Un 422 o un 503 se muestran con textoError.
Reversas, export, QR y el alta de vencimientos quedan afuera.
