P1-27: con `/?alta=pendiente` la home abre `/alta`; sin esa query la landing no cambia.

## Decisión
El callback sigue respondiendo 302 a `/?alta=pendiente` cuando no hay tenant ni `next` (PRD-AU-02).
`index.astro` lee `alta` en el request y, si el valor es `pendiente`, devuelve el redirect a `/alta`.
Cualquier otra visita a `/` renderiza la landing como hasta ahora.
No se toca `callback.ts` ni `alta.astro`.
El test pide la home con y sin la query y mira el destino de la respuesta.
