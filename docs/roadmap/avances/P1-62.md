P1-62: el cajero elige un cliente real y el servidor frena el fiado que pasa el tope de la ficha.

## Decisión
El tope 0 de `customers.tope_centavos` es límite abierto, no techo cero.
`resolverCredito` es el único constructor de `CreditoResuelto`.
`venta_a_cuenta` recibe ese crédito. El JSON ya no trae tope ni saldo.
La venta lockea la ficha, suma el saldo y responde 404 si no hay fila.
Sin base no hay ficha, así que no se vende en memoria.
El empleado que pasa el techo recibe 403 con el disponible. El dueño entra.
`/venta` manda el id del click, no un tope escrito a mano.
