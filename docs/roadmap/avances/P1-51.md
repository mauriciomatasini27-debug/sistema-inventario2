P1-51: /panel/caja descarga el historial con GET /api/cash/export.

## Decisión
El API de export ya existía. El dueño tenía que pedirlo con curl.
El botón está en últimos movimientos y pide el CSV sin query, porque la tarjeta no tiene filtros.
La respuesta ok se baja como caja-historial.csv. El archivo conserva el BOM que manda el API.
Un 403, un 422 o un 503 se muestran con textoError. Un fallo de red usa el mismo aviso que el resto de la caja.
No hay POST. QR, retiros, reversas, cierre y turnos no cambian.
