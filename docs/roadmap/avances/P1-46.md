P1-46: las TopPills del shell ocultan módulos fuera del plan, igual que el hub.

## Decisión
El hub ya filtraba las tarjetas y las pills con el índice del plan.
Las páginas del shell mostraban todas las pills, también las de módulos apagados.
El filtro de ids queda en una función y el shell la llama al leer el índice.
Si el índice falla, las pills siguen visibles.
La barra usa inline-flex, así que el shell repite la regla que esconde el atributo hidden.
Ventas pendientes y el upsell siguen solo en el hub.
